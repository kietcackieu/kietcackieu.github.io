# HƯỚNG DẪN DÀNH CHO TRƯỜNG HỢP 2 (1 REPOSITORY DUY NHẤT)

Kho lưu trữ GitHub: kietcackieu.github.io
Gồm đúng 2 file:
1. index.html  -> Trang hiển thị công khai (https://kietcackieu.pages.dev/)
2. setup.html  -> Trang cài đặt của riêng bạn (https://kietcackieu.pages.dev/setup.html)

---

## CÁCH SỬ DỤNG:

### Bước 1: Tải cả 2 file lên GitHub
1. Mở repository `kietcackieu.github.io` trên GitHub.
2. Chọn Add file -> Upload files.
3. Kéo thả cả 2 file `index.html` và `setup.html` vào.
4. Bấm Commit changes.

### Bước 2: Dùng trang setup để chỉnh sửa
1. Mở link: https://kietcackieu.pages.dev/setup.html
2. Tại đây bạn thoải mái:
   - Chọn video/ảnh từ máy bạn
   - Sửa tên, đổi bio, chỉnh chữ màn hình khóa
   - Nhìn sang màn hình Live Preview bên phải xem thử trực tiếp
3. Khi ưng ý, bấm nút "Xuất file index.html để đẩy lên GitHub" ở góc trên bên phải để tải file index.html mới về máy.

### Bước 3: Cập nhật file index.html mới
- Đẩy file `index.html` vừa tải về lên đè file cũ trên GitHub.
- Xong! Mọi người vào https://kietcackieu.pages.dev/ sẽ thấy giao diện mới, và KHÔNG AI có thể sửa được!
